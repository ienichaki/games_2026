para jogar o game snake deve-se utilizar as setas do computador ou as teclas wasd para mover-se pelo mapa,evitando seu proprio corpo e comendo as maças,tambem deve ser evitado o obstaculo laranja no meio do mapa.
as diferenças do senac snake para o abtual jogo da cobra sao suas cores que estâo em uma paleta mais escura que o original e o obstaculo no meio do mapa.
o jogo  senac snake foi criado pelos estudantes joicy ienichaki e vitor paim da turma 202.
